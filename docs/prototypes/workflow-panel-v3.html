⑨ dismiss 交互语义

dismiss 语义（M2）：
1. 用户关闭面板 → 记录 { runId, at }（runId 取关闭时 payload 的 runId，无则 null——不回退 activePromptRunId）。
2. 时间窗 3s：关闭后 3 秒内的自动打开被抑制（防误开）。
3. 同 runId 永久抑制：同一次运行的面板被手动关闭后，该 runId 不再自动重开（意图尊重）。
4. 用户手动打开面板 → 清除 dismiss 窗（后续自动打开恢复）。
5. 生命周期切换（activateProject/deleteThread/archiveThread/newSession）→ 幂等关闭，不写 dismissed。
